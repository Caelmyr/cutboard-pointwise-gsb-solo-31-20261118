# CutBoard 图片裁片排版

普通图片工作产品：把PNG/JPEG素材作为有独立原图裁剪框的裁片，手动按成品宽高、旋转、页号和位置排版；检查越界、相交和间隔；保存后输出各页PNG及完整ZIP。分组字段用于分拣标签，不会自动改变位置。演示素材为程序合成卡片，不是真实照片。

运行：`docker compose up -d --build`，访问 http://127.0.0.1:18934 。停止：`docker compose down`。数据位于独立命名卷solo34-cutboard_cutboard-data，down不删除卷。后台依赖Python3.11或3.12；requirements.txt锁定直接依赖。无Docker可运行`pip install -r requirements.txt`后`CUTBOARD_DATA_DIR=./data python -B app.py`。

操作：加入合成卡片或上传素材，建立空白排版，设置加入裁片宽高和分组并加入；右侧选择裁片修改位置、页号、旋转及尺寸；原图裁剪框使用原图像素坐标。透明边裁剪只根据alpha>0寻找包围框。撤销/重做最多40次；复制排版与原排版独立。ZIP中layout.json可在保留原素材的本工作区恢复为新排版；ZIP不支持一键导入全部原图。PNG按纸面像素输出，非物理毫米或打印DPI承诺。

自动直切排版：在工作台对1–8个裁片、纸面宽高不超过512像素的排版生成方案，按当前纸面尺寸与间隔全量重排；成品宽高、原图裁剪和图片内容不变，允许旋转的裁片只取0或90度，不允许的保持当前方向，纸边不额外留白。每页都可依次用贯穿当前剩余矩形的横切或竖切把裁片分开，切线落在裁片间隔通道内、不穿过裁片，预览图给出每刀方向、像素位置、贯穿矩形和执行顺序。“省纸”允许同名分组跨页并取最少页数；“整组”要求同组裁片在同一页，再取最少页数，整张纸放不下的组会明确列出且不会被偷偷拆组。方案仅在预览后手动采纳才生效，采纳是一次普通编辑，可一次撤销回到原排版；丢弃不改变原排版。预览后若修改过裁片或纸面，旧方案立即标记失效且无法覆盖新编辑，需重新生成。

正常功能：图像解码上传、合成示例、纸面尺寸设置、裁片缩放、手动定位、多页编排、直角旋转、原图裁剪、透明边裁剪、裁片复制与删除、间隔/越界检查、分组管理、撤销重做、独立复制排版、JSON恢复、单页PNG与含原图ZIP导出、自动直切排版（省纸/整组、切割顺序预览）。/prepare为独立可用的图片准备室，含常规图像校正、校准、质量诊断、比较及导出流程。此项目复用其自有图像引擎；主工作台功能不依赖准备室持久化。

有限容量：上传最长边2048、12MB；纸面64–1024像素（自动排版仅接受宽高≤512），每排版40裁片、1–20页（自动排版每次仅处理1–8个裁片）；裁片允许暂存越界或重叠并显示警告。裁片缩放采用Lanczos，RGBA alpha合成，细线可能有重采样变化。不同页面可以使用不连续页号。允许后续旋转标记仅是裁片属性；自动排版只在该标记允许时选用90度，手动旋转不受该标记限制。自动排版为精确子集DP求解，给定约束下输出最少页数；最少页数相同时按占用面积等确定规则给出唯一方案。
